## 🤖 Stage 3: Predictive Modelling and Machine Learning

Stage 3 focused on applying **machine learning techniques** to build and evaluate predictive models for a selected attribute within a shared dataset. The goal of this stage was to compare different modelling approaches and assess their effectiveness in making predictions relevant to the chosen domain.

---

### 🎯 Prediction Target and Dataset
As a group, a single **target attribute** (quantitative or nominal) was identified for prediction, along with an appropriate dataset containing this attribute. The group jointly defined the **measure of success** used to evaluate model performance and justified its suitability for the prediction task.

The dataset was split into **training** and **test** sets, with at least **10% reserved for testing**, ensuring fair and unbiased evaluation of all models.

---

### 🧠 Model Development
Group members coordinated to select **distinct machine learning methods**, avoiding duplication and enabling meaningful comparison across approaches. Each member then individually:
- Used **Python** (e.g. `scikit-learn, matplotlib, pandas`) to train a predictive model on the training data
- Tuned hyperparameters using only the training dataset
- Applied any necessary data preprocessing (e.g. scaling or encoding)

The test dataset was strictly reserved for final evaluation and was not used during training or tuning.

---

### 📊 Model Evaluation (Part A)
Individually, each member:
- Evaluated their model using the agreed success metric on the test data
- Reported the evaluation results and discussed model performance
- Documented their methodology, code, and results in their own section of **Part A** of the report

---

### 📘 Comparative Analysis (Part B)
Part B of the report was written collaboratively and targeted readers with an interest in **machine learning**. This section:
- Compared the different predictive models produced by the group
- Discussed strengths, weaknesses, and trade-offs between approaches
- Drew conclusions about which methods performed best and why

---

### 📄 Deliverables
Stage 3 required two submissions:
1. A **PDF report** containing:
   - An overview of the dataset, prediction target, and data split
   - Individual modelling and evaluation sections (Part A)
   - A comparative discussion of models (Part B)
2. A **compressed folder** containing:
   - Datasets used
   - Python notebooks for machine learning/predictive model training, tuning, and evaluation
   - Any metadata or supporting files

Both submissions were made by one group member on behalf of the entire group, with all members receiving the same mark.

---

Stage 3 emphasized **predictive accuracy**, **methodological rigor**, and **clear communication** of machine learning concepts and results.
